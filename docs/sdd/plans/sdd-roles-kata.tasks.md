**Honest notes:**
- Tasks authored **pending** before any code existed — deliberately, the item-4 fabricated-status failure mode the kernel outlaws. Statuses flipped only when the named proof existed.
- **Wilson-formula bug caught by verification before any golden was cut:** the first integer `wilson_interval` had a radicand missing a factor of `n` in both terms, producing intervals ~5× too wide (non-overlap unachievable even for extreme effects — a broken instrument). Caught by testing the integer math against a float reference across 15 (k,n) cases *before* generating fixtures; corrected radicand `R = Z2N·(4·n·k·(n−k)·Z2D + n²·Z2N)` matches the float reference to ≤1 unit and always widens. Lesson: verify the statistics against a reference before cutting the golden they'll be frozen against.
- **Float→integer schema decision (decomposition correction):** the design brief carried `mutation_score` / `crap.mean` as floats (`0.86`, `2.1`). Made them integers (`mutation_score` on [0,10000], CRAP integers) to hold the zero-float discipline the whole rig rests on — any float in the committed corpus would undermine the byte-identical guarantee. Recorded here, seam doc notes the 0.86→8600 encoding.
- **Digest-triangle hardening (found during tamper authoring):** the first `analyze` compared only `prereg["prereg_digest"] == PREREG_DIGEST`, so a doctored constant with a stale-but-matching stored digest slipped through (exit 0). Fixed `analyze`/`plan` to recompute the digest from the prereg's OWN constants and require self-consistency AND code agreement — closing the hole before it reached the corpus.
- Item-5 S6 left `invocation.model` unset "as a deployment parameter for item 6"; KA07 discharges that (populated `"UNBOUND"` per role). The one place item 6 edits item-5 catalog data — recorded in ADR 0004, not silent.
- Placeholder workload (KA06): real kata names (C1–C4) are a run-time fill; the arithmetic still pins the pre-registered 12/240 so the experiment shape is gate-real now. `provenance_note` in the workload file records this.
