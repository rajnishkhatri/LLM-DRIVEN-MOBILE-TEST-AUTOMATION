03The worker's routine

Under the hood every agent runs the same loop — ReAct: Reason → Act → Observe, repeat until done. You can count the laps in the trace IDs.

guardrail-pre 205 ms→ reason "exactly what I need"→ act: tool_use lap -0→ Lambda + S3 952 ms→ observe JSON→ compose lap -1→ guardrail-post 203 ms

Steps 1–4 had no tools, so every request was a one-lap loop: think, answer, done. The S3 lookup was the first two-lap request (traceId …-0, …-1). Multi-agent collaboration is the same loop where the tools are other loops; the router mode is a shortcut that skips the loop entirely — one 12-token classification, then a transfer.

05Press a button twice

Today's biggest transferable lesson: know which family a command belongs to before leaning on the retry habit.

Refuses

409create-agent, create-function, add-permission — duplicate press bounces off with a Conflict error. Safe and loud.

Overwrites

=put-role-policy, update-agent — each press replaces the whole thing. Safe but silent; re-send every field or lose it.

Appends

+1create-guardrail-version, update-agent-alias — every press mints a new snapshot. Today's orphan pile: guardrail v2, agent versions 2–7.

06Scars of the day

The reader was stale, not the paper

After swapping IAM policies, Bedrock kept refusing a model the role plainly allowed — even Haiku, which had worked all day. IAM propagation lag. The retry, unchanged, succeeded a minute later.

S3 wears a 403 disguise

A missing key returned AccessDenied, not "not found" — without ListBucket, S3 refuses to admit which keys exist. One prefix-scoped grant turned the lie into an honest NoSuchKey.

The echo always says PREPARING

prepare-agent's response is an acknowledgment, not a status. Re-running it to check restarts the compile. Only get-agent tells the truth.

A release pin pins everything

The specialists' aliases kept serving their pre-guardrail snapshots after the wall went up. Patching security meant cutting a new version and re-pointing — deploys, not edits.

07The meter

Idle cost

$0Agents, guardrails, aliases, action groups, Lambda, S3 objects — all pay-per-use. Nothing added today bills while it sleeps.

Routing economics

12output tokens to route a message (Haiku). The answer costs 100–500. Cheap model decides, expensive model answers — that's the whole trick.

Model spread

3×Haiku ≈ $1/$5, Sonnet ≈ $3/$15 per Mtok. If 80% of traffic is tier-1 chatter, per-desk models roughly halve the bill.

Memory tax

+Sessions replay the whole transcript each turn (311 → 439 → 1,287 input tokens as the day went on). Tools add their schemas on top. Long chats get dearer per message.
