The Front Desk

A desk in front of the claims office. A clerk reads what each visitor wants and sends them to the right window. Behind one window sits an agent whose whole thought process runs in the open. Two frameworks — Agent Squad routes, Strands answers — and both were fired live against the pipeline.

§01Floor plan

Solid arrows carry the customer. Dashed arrows carry data about the work. The upper box is the desk; the lower box opens up one clerk's head.

§02The architecture, one line of truth each

Strands = code-first agent

Three things to a constructor: a model, a system prompt, a list of tools. You call it like a function — agent("...") — and the whole loop runs in your process, not inside AWS.

The loop

Model-driven, code-executed. The model decides which tool and when; your Python runs it, in-process and synchronous, feeds the result back, and repeats until there's a final answer. You can breakpoint every hop.

@tool is the contract

The decorator turns a plain function into a callable tool. Strands builds the JSON schema the model sees from the type hints and the docstring — so the signature is the API, not decoration.

BedrockModel

Just a model handle — swap models by string. Pin identity by handing it a boto session, the way the pipeline's own creds are pinned. Here it's Haiku: triage is light work.

Agent Squad = a router

It does not answer. An orchestrator holds a set of specialists and a classifier, dispatches each message to the chosen one, and keeps per-session history.

The classifier

Itself an LLM call. It reads the message plus every specialist's description and returns the best match with a confidence — the routing decision, made in your process where you can log it.

Descriptions are the knob

Routing has no rules table. The only lever is the words in each description=. Routing quality is description quality; a vague description misroutes silently.

Session memory

The orchestrator remembers the conversation per user and session, so a bare follow-up like "and how much was it?" still lands at the window that answered last.

The adapter seam

Agent Squad wants an agent with an async process_request; a Strands agent has none. One class — StrandsSpecialist — bridges them. That single seam is where the two frameworks compose.

Managed vs code-first

The Bedrock Agents lab ran the loop and the routing inside AWS. Strands + Agent Squad run both in your process: visible, loggable, testable, portable. Same shape, opposite ends of the control dial.

§05Scars

the description is the program

There is no routing code to read — the behavior lives entirely in three sentences. Tuning the system means editing prose. Powerful and unnerving: a typo in a description is a logic bug with no stack trace.

fails closed, and loud

When the classifier call died, nothing routed anywhere — No Agent, with the error surfaced in plain sight. A dead router is not a wrong answer quietly served; it is no answer, obviously. The loud failure is the good failure.

read the framework's defaults, not just yours

Both frameworks call the same Haiku, yet shipped different sampling defaults. The model's rule — one of temperature or top_p — bit whichever framework sent both. The knob you didn't set is still a knob.
