# Ripple interview — bundle index

OKF bundle. Each entry is a typed Concept. See the convention in
[CONVENTIONS.md](../../docs/CONVENTIONS.md). The exercise artifacts themselves
(worksheet, ADRs, diagrams, eval spec, build) live in `ari/` at the repo root,
outside OKF — this bundle holds the authored prep notes around them.

- [Ripple influence rounds: five story cards](ripple-influence-round-cards.md) — Leadership-story cards for the influence/behavioral rounds: governing sentence, scene, three moves, result, lesson per card, plus memorization and trigger rules.
- [Eval layer talk track — Ari panel walkthrough](eval-layer-talk-track.md) — Presentation notes for the evals portion of the 75-minute panel: golden set, schema, failure taxonomy, release gates — governing sentences, the numbers to hold, the Q-065 set piece, Q&A ammunition.
- [Code tour talk track — Ari module walkthrough](code-tour-talk-track.md) — Recall notes for the code portion: a governing sentence per module, the 9-step live-demo run order, the numbers, seven warts to own, and all 22 interviewer Q&As in concise plain English.
- [Panel answer anchors — the scripted 75 minutes](panel-answer-anchors.md) — Pyramid cards for the full panel script: 17 questions plus 4 pressure probes, each with the line to lead with, the receipts behind it, and the trap it tests. Q14 verified live against the CLI.
- [Ari v2 — enhancement and implementation plan](ari-v2-breakdown.md) — Implementation design on the existing hexagon: functional and non-functional requirements, what stays out of scope, three pillars with the decision behind each, and the eight-step build sequence that keeps the twelve eval gates green.
