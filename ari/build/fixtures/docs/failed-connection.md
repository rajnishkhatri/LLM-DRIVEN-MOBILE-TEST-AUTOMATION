# Fix a failed bank connection

1. Go to **Settings -> Connections -> Banks** and find the connection marked
   **Failed**.
2. Click **Reconnect** and re-authorize. Most failures are expired credentials.
3. If it still fails, check that the bank has not changed its access
   requirements, then retry.
4. Still stuck? Raise a support ticket and we will investigate the feed.
