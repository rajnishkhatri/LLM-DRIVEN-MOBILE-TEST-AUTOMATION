# Rotate your API keys

1. Open **Settings -> Developer -> API keys**.
2. Click **Rotate** next to the key you want to replace. A new key is issued
   and the old one stays valid for a 24-hour grace window.
3. Update the key in your integrations before the grace window ends.
4. Click **Revoke now** on the old key once every integration is updated.
